# Gold-Standard Data

This directory contains the curated reference data used to evaluate the extraction pipeline.

- `gold_standard_set.json`: Main gold-standard annotation set used by the evaluation scripts and fine-tuning pipeline.
- `gold_standard_export.csv`: ORKG comparison export used as the input for regenerating `gold_standard_set.json`.
- `papers_list.json`: Paper metadata and arXiv/PDF URLs used by batch extraction, Grete jobs, and fine-tuning data preparation.

The annotations are derived from the ORKG Generative AI Model Landscape comparison.
